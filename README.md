# Azerbaijani prosodic Analysis and Stress Detection

## 1. Project Overview
This project focuses on the acoustic realization of **Azerbaijani word stress** and its phonetic patterns. As a student currently conducting research in Baku, Azerbaijan, I aim to develop a Python-based automated pipeline to extract acoustic features (F0, duration, intensity) to detect stress positions.

## 2. Research Interests
* **Acoustic Phonetics:** Analyzing prosodic features using `Parselmouth` (Praat-in-Python).
* **Second Language Acquisition (SLA):** How Chinese learners acquire the prosody of Turkic languages.
* **Computational Linguistics:** Automating phonetic data processing for low-resource languages.

## 3. Theoretical Framework
Following the framework of **Phonetic Data Analysis (Ladefoged, 2003)**, this project treats Fundamental Frequency (F0) and duration as primary acoustic correlates of stress.
